# Netflix Clone

This project is a clone of the Netflix landing page created using HTML, CSS, and JavaScript. The goal was to replicate the design and functionality of Netflix's homepage to practice front-end development skills.

## Features

- **Responsive Design**: The website is fully responsive and adapts to different screen sizes.
- **Modern Styling**: Utilizes CSS for styling and layout.
- **Interactive Elements**: JavaScript is used for interactive elements and animations.

## Live Demo

Check out the live demo of the project [here](https://adeelahmed09.github.io/Netflix-clone/).

## Technologies Used

- HTML (82.5%)
- CSS (12.7%)
- JavaScript (4.8%)

## Installation

To run this project locally, follow these steps:

1. Clone the repository:
    ```bash
    git clone https://github.com/adeelahmed09/Netflix-clone.git
    ```
2. Navigate to the project directory:
    ```bash
    cd Netflix-clone
    ```
3. Open `index.html` in your preferred web browser.

## Usage

Feel free to explore the code and modify it as you like. The project is a great starting point for learning responsive web design and front-end development.
